Digits ZATCA | Tax Total (Fix Issue)

Temporary fix for the recurring ZATCA chatter warning BR-KSA-EN16931-09 on SAR invoices. Uninstall it when Odoo 18 core restores the second TaxTotal node.

Fix Issue Odoo 18 l10n_sa_edi

The warning in Odoo

After a successful send, ZATCA accepts the invoice and Odoo posts this yellow message on the invoice chatter. The invoice is valid; the XML structure is incomplete for SAR documents.

Screenshot: chatter warning [202] BR-KSA-EN16931-09 — Only one tax total (BG-22) without tax subtotals (BG-23) must be provided when tax currency code is provided.

1. Cause

Odoo 18 always sends TaxCurrencyCode (SAR). A core change then omitted the second TaxTotal on SAR invoices.

2. ZATCA rule

When tax currency code is present, XML must include one cac:TaxTotal without TaxSubtotal (BT-111).

3. This module

Restores that second node for SAR invoices. Foreign-currency invoices are left unchanged (no duplicate).

Required XML shape

<cbc:DocumentCurrencyCode>SAR</cbc:DocumentCurrencyCode>
<cbc:TaxCurrencyCode>SAR</cbc:TaxCurrencyCode>

<cac:TaxTotal>
    <cbc:TaxAmount currencyID="SAR">...</cbc:TaxAmount>
    <cac:TaxSubtotal>...</cac:TaxSubtotal>   <!-- WITH breakdown -->
</cac:TaxTotal>
<cac:TaxTotal>
    <cbc:TaxAmount currencyID="SAR">...</cbc:TaxAmount>
    <!-- WITHOUT TaxSubtotal  (restored by this module) -->
</cac:TaxTotal>

Install

  1. Install Digits ZATCA | Tax Total (Fix Issue) (digits_zatca_tax_total).
  2. Depends only on l10n_sa_edi.
  3. New invoices sent to ZATCA after install will not show this warning.
  4. Already-sent invoices stay accepted; they are not re-submitted.
